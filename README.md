# AI Handbook — Chapter 14

Python examples for Chapter 14 of the AI Handbook. The chapter covers basic neural-network computations, activation functions, forward propagation, training workflows, TensorFlow/Keras, PyTorch, and automatic differentiation.

## Examples

| File | Topic |
| --- | --- |
| `14.1.py` | Weighted sums and ReLU |
| `14.2.py` | ReLU, sigmoid, and softmax |
| `14.3.py` | A small two-layer neural network |
| `14.4.py` | Python and package environment check |
| `14.5.py` | TensorFlow/Keras Iris classifier |
| `14.6.py` | Training history and test evaluation |
| `14.7.py` | PyTorch automatic differentiation |
| `14.8.py` | Training a PyTorch XOR classifier |

## Requirements

The examples use NumPy, scikit-learn, TensorFlow, and PyTorch. Install the required packages with:

```bash
python -m pip install numpy scikit-learn tensorflow torch
```

## Running the examples

Run any example from the repository root:

```bash
python 14.1.py
python 14.5.py
python 14.8.py
```

Not every script requires every package. `14.4.py` checks whether NumPy, TensorFlow, and PyTorch are available in the current Python environment.
